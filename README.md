# CyberShieldAI

## AI-Powered SMS, Email, and URL Phishing Detection System

CyberShieldAI is a cybersecurity project that uses Machine Learning and Natural Language Processing (NLP) to detect phishing attacks in SMS messages, emails, and URLs. The system helps users identify malicious content and improve online security through real-time analysis.

## Features

* SMS Phishing (Smishing) Detection
* Email Phishing Detection
* URL Phishing Detection
* Machine Learning-Based Classification
* NLP-Based Text Processing
* User-Friendly Web Interface
* Real-Time Threat Prediction

## How to Run

1. Clone the repository:
   git clone https://github.com/yourusername/CyberShieldAI.git

2. Navigate to the project folder:
   cd CyberShieldAI

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python app.py

5. Open the browser and access:
   http://127.0.0.1:5000

## Project Objective

The objective of CyberShieldAI is to protect users from phishing attacks by automatically analyzing SMS messages, emails, and URLs using Artificial Intelligence and Machine Learning techniques.
